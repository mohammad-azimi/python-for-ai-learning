# Python for AI Learning

My personal learning repository for studying Python from the fundamentals, with a focus on Artificial Intelligence, Machine Learning, and Data Science.

## Goals

The main goals of this repository are to:

* Learn Python step by step from the basics
* Practice each concept with small exercises
* Build a strong foundation for Artificial Intelligence
* Learn important Python libraries for data analysis and machine learning
* Keep organized notes for future review
* Build small projects while learning

## Learning Path

The planned learning path is:

1. Python Basics
2. Variables and Data Types
3. Operators
4. Conditions
5. Loops
6. Lists, Tuples, Sets, and Dictionaries
7. Functions
8. File Handling
9. Error Handling
10. Object-Oriented Programming
11. NumPy
12. Pandas
13. Matplotlib
14. Statistics for Machine Learning
15. Machine Learning Fundamentals
16. PyTorch
17. Deep Learning

The structure may evolve as I learn new topics.
